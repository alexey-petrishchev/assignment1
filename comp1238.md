## Week 1 - History
- Number systems- the first number system Cuneiform used wedges to record numeric data
- Early Printing Techniques- Cylinder Seals were used in Mesopotamia as stamps

  
## Week 2 - Bits and Bytes
- Memory type - Volatile looses data when powered off, Non-Volatile retains
data after shut down.
- Number Systems - Decimal with Base 10, Binary with Base 2, and hexadecimal with Base 16


## Week 3 - Text Structure
-  Markdown language - #Title# ##paragraph, list * item or - item
-  HTML list tags  \<ul> \<li>point 1 \</ul> is ordered list with points


## Week 4 - Keyboards and Editors
- Advanced Search using regular expression to find more specific data, wildcard character *
- _config.yml is for customizing appearance of webpage


## Week 5 - CLI
- Command Line interface 
     - pwd - present working directory,
     - ls - list files in current directory
     - cat- display contents of file
     - mkdir - create new directory
- SFTP - secure file transfer protocol, is used to move files 
between client and server with encryption.
